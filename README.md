# Aplikasi To-Do List

Aplikasi daftar tugas sederhana yang dibuat secara kolaboratif menggunakan Git
dan GitHub sebagai tugas pembelajaran.

## Anggota Tim
| Nama | Tugas |
|------|-------|
| (isi nama kamu) | Tampilan: `index.html` dan `style.css` |
| Ahmad Rizky Wahyu Pratama | Logika: `script.js` |

## Fitur
- Menambah tugas baru (tombol atau tekan Enter)
- Menandai tugas selesai
- Menghapus satu tugas atau semua tugas yang selesai
- Filter: semua, belum selesai, selesai
- Data tersimpan di browser, jadi tidak hilang saat halaman dimuat ulang

## Teknologi
- HTML
- CSS
- JavaScript
- Git dan GitHub

## Cara Menjalankan
1. Clone repository:
   `git clone https://github.com/USERNAME/todo-list.git`
2. Masuk ke folder `todo-list`
3. Buka `index.html` di browser

## Alur Kolaborasi
- Setiap orang bekerja di branch masing-masing
- Perubahan digabung ke `main` melalui Pull Request
- Sebelum mulai bekerja, jalankan `git pull origin main`
